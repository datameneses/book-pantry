# Book Pantry

A personal archive of books: what I've read (with ratings, status and where I read it) and what's on the to-read list. EN / PT-BR toggle.

Plain HTML/CSS/JS, no build step, hosted on GitHub Pages. Same look and structure as the sibling `coffee-pantry` and `wine-pantry` sites.

## Structure

- `index.html` — **Read**: dashboard, sort/filter toolbar, one card per book
- `tbr.html` — **To Read**: a simple list of cards
- `data/books.json`, `data/tbr.json` — the content (generated by `scripts/build_data.py`, or edit the JSON directly)
- `images/covers/` — cover images
- `css/style.css`, `js/main.js` — shared styles, i18n and helpers

## Rating scale

1–2: not started/finished · 3.0: didn't like · 3.5: average · 4.0: good · 4.5: very good · 5.0: exceptional

## Status values

`reading`, `read`, `highlighted` (read + highlighted), `distilled` (read + highlighted + distilled into notes)

## Adding a book

Add an object to `data/books.json` or `data/tbr.json` (fields: `title`, optional `title_pt`, `author`, `year`, `genre`/`genre_pt`, `synopsis`/`synopsis_pt`, `format` = `Libby` | `Kobo Store` | `Physical`, `image`; read books also `rating`, `status`, optional `lastRead` as `YYYY-MM`) and drop the cover in `images/covers/`.

## Viewing locally

```
python3 -m http.server
```
